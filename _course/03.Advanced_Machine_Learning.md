## Advanced Machine Learning

**Introduction**\
This course systematically introduces the fundamental theories and algorithms of statistical machine learning, with an emphasis on the mathematical principles, model derivation, and practical applications of machine learning methods. The course covers regression, classification, support vector machines, neural networks, generative models, and clustering.
