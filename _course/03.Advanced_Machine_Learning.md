## Advanced Machine Learning

**Introduction**\
This course systematically introduces the fundamental algorithms and theories of machine learning, with an emphasis on the mathematical principles, model derivation, and practical applications of machine learning methods. The course covers regression, classification, support vector machines, neural networks, generative models, and clustering.
- Instructor: Qing-Yuan Jiang ([jiangqy@njust.edu.cn](mailto:jiangqy@njust.edu.cn))
- TA: Peng Cheng.
- Location: Room III-514.
